# airquality-project
Membuat alat pengukur kualitas udara menggunakan sensor MQ-7 dan MQ-135

Sensor MQ7 (A0) ---> GPIO 1 ESP32C3
Sensor MQ135 (A0) ---> GPIO 0 ESP32C3
Sensor DHT22 (out) --> GPIO 3 ESP32C3
OLED (SDA) --> GPIO 8
OLED (SCL) ---> GPIO 9

Untuk rangkaian voltage divider lihat gambar skemanya
